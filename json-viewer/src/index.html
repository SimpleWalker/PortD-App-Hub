Keyboard shortcuts

    

      
Ctrl+OOpen a file

      
Ctrl+FSearch keys and values

      
Enter, F3Next match (Shift for the previous one)

      
Up / DownMove through the tree

      
Right / LeftOpen / close an item, or go to its first child / its parent

      
Enter, SpaceOpen or close an item

      
*Open everything below the item

      
Home / End, Page Up / DownFirst / last item, a page at a time

      
Ctrl+CCopy the item's value

      
Ctrl+Shift+CCopy the item's path

      
Shift+F10, Menu keyMore copy choices

      
RRaw text; Esc goes back to the tree

      
F1This list
