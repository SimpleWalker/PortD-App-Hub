Characters

          
.any character except a line break (any at all with the s flag)

          
\d \w \sa digit · a letter, digit or _ · a space, tab or line break

          
\D \W \Sanything except those

          
[abc] [^abc] [a-z]one of a, b, c · anything but a, b, c · a to z

          
\. \\ \( \[a real dot, backslash, bracket: put \ before . * + ? ( ) [ ] { } | ^ $ \

          
\t \n \rtab · new line · carriage return

          
\p{L} \p{Lu}any letter · an upper-case letter (needs the u flag)

          
How many

          
* + ?0 or more · 1 or more · 0 or 1

          
{3} {2,} {2,5}exactly 3 · 2 or more · 2 to 5

          
*? +? ??as few as possible (lazy)

          
Where

          
^ $start · end of the text (of each line with the m flag)

          
\b \Ba word edge · not a word edge

          
(?=x) (?!x)followed by x · not followed by x

          
(?<=x) (?<!x)after x · not after x

          
Groups

          
(abc)a group: kept as $1, $2…

          
(?<name>abc)a named group: kept as $<name>

          
(?:abc)a group that is not kept

          
a|ba or b

          
\1 \k<name>the same text as group 1 · as the named group

          
In Replace

          
$1 $<name>a group's text

          
$&the whole match

          
$` $'the text before · after the match

          
$$a dollar sign

          
Examples

          
^\s*$an empty line (with m)

          
\b\d{1,3}(\.\d{1,3}){3}\bsomething shaped like an IPv4 address

          
(?<user>[\w.-]+)@(?<domain>[\w-]+(\.[\w-]+)+)something shaped like an email address

          
\[(ERROR|WARN)\][ERROR] or [WARN] in a log
