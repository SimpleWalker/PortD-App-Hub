Table Viewer

Open a CSV or TSV file to see it as a table.

You can also drop a file on this window.

This window is not allowed to use the clipboard. The text is selected below: press Ctrl+C to copy it.

Keyboard shortcuts

Ctrl+OOpen a file
Ctrl+SSave as
Ctrl+FFilter rows
EscClear the filter, or close a dialog
Arrow keysMove around the table
Page Up / Down, Home / EndMove a page, or to the first or last column (with Ctrl: first or last row)
Shift + Up / Down, Shift+clickSelect several rows
Ctrl+clickAdd or remove one row
Ctrl+ASelect all shown rows
Ctrl+CCopy the selected rows (or all shown rows) as TSV
SSort by the current column: up, down, off
F1This list

Click a column heading to sort by it. Drag the edge of a heading to change the column's width.
