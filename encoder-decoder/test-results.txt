  ok    Ctrl+Z brings it back

URL, Hex and HTML

  ok    URL encode is encodeURIComponent
  ok    Whole address keeps : / ? & =
  ok    decoding turns + into a space (can be turned off)
  ok    a broken % is explained
  ok    Hex shows the UTF-8 bytes, spaced, and counts them
  ok    separator and upper case are options
  ok    decoding accepts 0x, spaces and commas
  ok    an odd number of digits is explained
  ok    HTML encode escapes & < > " '
  ok    …and can write non-ASCII as numbers
  ok    decoding handles named and numbered entities, and lists unknown ones

JWT
  ok    it says plainly that the signature is not checked
  ok    header and payload are shown as formatted JSON ("Bearer " is fine)
  ok    an old token is marked expired, with exp and iat in local time and UTC
  ok    a current token says when it ends; a future nbf says it is not valid yet
  ok    Copy copies the payload JSON
  ok    an encrypted token (5 parts) is explained
  ok    something else is explained
  ok    an unsigned token is marked "Not signed"

Hash
  ok    SHA-1, SHA-256, SHA-384, SHA-512 and MD5 of typed text are all right
  ok    MD5 is labelled "not secure"
  ok    Compare finds which hash matches, whatever the case or a label in front
  ok    …and says when nothing matches
  ok    each hash has its own Copy
  ok    Upper case is an option
  ok    a binary file is hashed byte for byte (all five right)
  ok    a text file is hashed as its UTF-8 bytes, and that is said
  ok    Back to text hashes the typed text again

Generate

  ok    5 GUIDs, each a random version 4 one
  ok    upper case and braces are options
  ok    1,000 at once, all different

  ok    strength is estimated in bits
  ok    with no kinds of character chosen it says so
  ok    a short digits-only password is marked weak
  ok    a passphrase of 6 capitalised words from the list, one with a digit
  ok    the list has hundreds of different words
  ok    Copy copies it

Keyboard, touch, theme, and what is kept
